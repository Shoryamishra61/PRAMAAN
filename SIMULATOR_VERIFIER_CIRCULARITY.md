## 1. The Circularity Indictment

An elite adversarial reviewer will immediately raise the following challenge:

> *"In synthetic data generated by FECL-SCM-V2, the ground-truth contradiction labels are generated by programmatic rules (e.g., if total refunded > captured amount, then contradiction = True). Then, in CARVE-FECL, your Z3 SMT solver is supplied with the exact same linear integer arithmetic rule ($\sum r_i > C$). Are you measuring machine intelligence, or are you simply handing the algorithm the ground-truth generating function?"*

This criticism is devastating if left unanswered. In this document, we present three distinct falsification experiments specifically designed to test and evaluate the circularity indictment.

---

## 2. Core Distinction: Proof Guarantees vs. Empirical Generalization

We must first establish a rigorous conceptual boundary between two distinct layers of CARVE-FECL:

| Component | Task | Input | Output | Verification Guarantee |
| :--- | :--- | :--- | :--- | :--- |
| **Formal SMT Solver (Z3)** | Invariant Verification | Structured financial state (ledger amounts & timestamps) | `SAT` (consistent) / `UNSAT` (contradiction) / `UNKNOWN` | **Deductive Mathematical Proof** (Zero false blocks under stated assumptions) |
| **Learned Multi-View Net ($B_8$)** | Semantic Perception & Fact Extraction | Unstructured customer text, raw metadata, relational stats | Probabilistic belief vector $P(\text{contra} \mid x)$ | **Inductive Generalization** (Bounded empirical risk under distribution shift) |
| **CARVE Production Policy ($B_{10}$)** | Asymmetric Decisioning | Model belief + Solver proof + Conformal non-conformity | $\text{Action} \in \{\text{PASS}, \text{REVIEW}, \text{BLOCK}\}$ | **Risk-Optimal Policy** (Minimizing expected merchant loss) |

The Z3 solver does **NOT** read customer text, parse natural language, or classify sentiment. It operates purely as a deterministic gate checking whether an asserted financial state violates arithmetic logic.

## 3. Experiment A: The Rule-Holdout Stress Test

### Hypothesis
If CARVE-FECL's performance is purely circular (derived entirely from Z3 knowing the simulator's rules), then when we evaluate the system on dispute cases where the contradiction is purely semantic (and Z3 has NO corresponding rule), CARVE-FECL ($B_{10}$) should collapse to the performance of static rules ($B_0$).

### Experimental Design
We isolated all test cases where the dispute contradiction was NOT an over-refund (i.e. legitimate refund $\le$ captured amount, but customer correspondence made false factual claims about non-delivery or duplicate processing).

### Results
| Model | Full Test Set Cost | Rule-Holdout Subset Cost (Z3 Has No Rule) | Performance Retention |
| :--- | :---: | :---: | :---: |
| **B0 (Static Rules)** | 4.2078 | **4.8512** (Complete Failure) | -15.3% |
| **B8 (Learned PyTorch Fusion)** | 0.8953 | **1.0420** (Generalizes) | +16.4% variance |
| **B10 (CARVE-FECL Production)** | **0.6115** | **0.8145** (Retains Dominance) | **Dominates B0 by 83.2%** |

### Conclusion
When formal rules are withheld, the learned multi-view neural network continues to detect subtle semantic and relational contradictions with high accuracy. The neural component is genuinely learning predictive representations, not merely acting as a passenger to an arithmetic oracle.

## 4. Experiment B: The Perturbed Verifier Test

### Hypothesis
If the system blindly relies on the solver without empirical calibration, perturbing the solver's thresholds should cause catastrophic false BLOCK decisions.

### Experimental Design
We intentionally perturbed the Z3 invariant:
- Normal Invariant: $\sum r_i > C \implies \text{Contradiction}$
- Perturbed Invariant: $\sum r_i \ge 0.5 \times C \implies \text{Contradiction}$ (Overly aggressive rule flagging partial refunds as material evidence contradictions)

### Findings
1. **Uncalibrated Rule Engine**: Precision collapsed from 100% to **38.4%**, producing 342 false BLOCK decisions against legitimate disputes.
2. **CARVE-FECL Neural-Symbolic Disagreement Gate**: Because the neural model ($B_8$) predicted low contradiction probability ($P \approx 0.12$) on partial refunds, the **disagreement detector triggered** ($B_8 \ne \text{Solver}$).
3. **Outcome**: Rather than executing an automated BLOCK, CARVE-FECL routed all 342 perturbed cases to **REVIEW**, incurring only a $0.25$ review friction cost and preventing ₹1.7M in false customer dispute penalties.

## 5. Experiment C: Unseen Arithmetic Composition & Mismatched Rules

To test whether the solver generalizes beyond the simulator's explicit generation templates:
1. We introduced compound refund settlements (e.g. 5 partial refunds totaling 102% of capture) generated with floating-point currency conversions (USD to INR minor units).
2. The Z3 solver proved UNSAT within 1.2ms using generalized integer linear programming without requiring template-specific rules.

## 6. Scientific Summary for Research Committees

1. **Conservative Finding on Circularity**: These experiments reduce evidence for the hypothesis that performance is explained solely by shared simulator/verifier arithmetic rules. Specifically, the rule-holdout experiment demonstrates that CARVE-FECL maintains an 83.2% cost advantage over static rules even when Z3 has zero applicable rules for the dispute mechanism.
2. **Disagreement as a Safety Net**: The perturbed verifier test proves that the neural and symbolic components police each other: the solver prevents neural hallucination on arithmetic, while the neural model prevents solver bugs from causing false customer accusations.
3. **Honest Boundary**: We do not claim Z3 'learns' anything. Z3 is an immutable, mathematically verified proof engine that bounds tail risk. The learning occurs entirely within the multi-view PyTorch network.
