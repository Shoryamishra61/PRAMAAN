# T112 — Interactive evidence debugger verification

Verified: 2026-09-01  
Requirement: PRD-022, SRS-027, API-011

## Implemented

- Default judge view is the financial evidence debugger, not the old dashboard/proof chapters.
- Six direct break controls cover wrong amount, incomplete ledger, contradictory communication,
  prompt injection, malformed money, and controlled extractor outage.
- Semantic extraction and deterministic ledger/policy stages are visually distinguished.
- Every returned finding exposes keyboard-operable source links based on its evidence references.
- Exact quote/span and normalized ledger facts remain visible.
- A user-attached matching refund record reruns the same policy and creates a live
  before/repair/after decision diff.
- Evaluation renders only the latest generated artifact or `NOT YET MEASURED`.
- No model confidence, savings claim, decorative AI feature, external provider call, or Razorpay
  write was added.

| Controlled `model_outage` simulation | `REVIEW / F_MODEL_UNAVAILABLE` |
| `4999.999` exact-decimal input | HTTP `422`; no decision |
| Matching processed ₹4,999 repair | `PASS`; no findings |
